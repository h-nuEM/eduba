# Leçon 5 – Inflexion verbale

## Résumé

**Hamtu et marû**

Le verbe sumérien change de forme selon l'aspect. Pour commencer, on peut retenir une opposition simple : **hamtu** correspond à une forme passée ou accomplie, tandis que **marû** correspond à une forme présente ou future.

Cette distinction ne fonctionne pas exactement comme les temps français ou anglais : il s'agit plutôt d'aspect verbal. Mais pour les premières leçons, l'opposition pratique est : *hamtu* = passé, *marû* = présent/futur.

**La forme hamtu**

La forme *hamtu* est souvent la forme régulière ou lexicale du verbe, celle qu'on trouve dans le vocabulaire. Dans les verbes transitifs à la 3e personne du singulier, un **-n-** peut apparaître avant la base verbale pour marquer le sujet : « il / elle ».

| Base   | Forme hamtu  | Sens                   |
| ------ | ------------ | ---------------------- |
| *du<sub>3</sub>*  | *mu-un-du<sub>3</sub>*  | il a construit         |
| *la<sub>2</sub>*  | *mu-un-la<sub>2</sub>*  | il a suspendu / étendu |
| *šum<sub>2</sub>* | *mu-un-šum<sub>2</sub>* | il a donné             |
| *dim<sub>2</sub>* | *mu-un-dim<sub>2</sub>* | il a formé             |

**La forme marû**

La forme *marû* se construit de plusieurs manières. Certains verbes ajoutent simplement le suffixe **-e** à la base verbale :

| Base   | Forme marû  | Sens                   |
| ------ | ----------- | ---------------------- |
| *la<sub>2</sub>*  | *mu-la<sub>2</sub>-e*  | il suspendra / étendra |
| *bad*  | *mu-bad-e*  | il ouvrira             |
| *dim<sub>2</sub>* | *mu-dim<sub>2</sub>-e* | il formera             |

Une deuxième possibilité est le redoublement de la base verbale. Le verbe est alors écrit deux fois : *gi<sub>4</sub>* → *gi<sub>4</sub>-gi<sub>4</sub>*, *gul* → *gul-gul*, *kar<sub>2</sub>* → *kar<sub>2</sub>-kar<sub>2</sub>*.

Une troisième possibilité est le changement de base. Le *marû* ne ressemble alors plus à la forme lexicale : *du<sub>11</sub>* devient *e*, et *de<sub>6</sub>* devient *tum<sub>2</sub>* ou *tum<sub>3</sub>*.

**Redoublement hamtu**

Le redoublement n'appartient pas seulement au *marû*. Certains verbes *hamtu* peuvent aussi être redoublés. En général, avec un verbe intransitif, le redoublement peut indiquer un sujet pluriel ; avec un verbe transitif, il peut indiquer un objet pluriel.

Pour distinguer un redoublement *hamtu* d'une forme *marû*, il faut regarder si la base a changé. Par exemple, *ĝar* donne *ĝa<sub>2</sub>-ĝa<sub>2</sub>* en *marû* ; donc *ĝar-ĝar* correspond plutôt à un redoublement *hamtu*. De même, *naĝ* donne *na<sub>8</sub>-na<sub>8</sub>* en *marû*, tandis que *naĝ-naĝ* reste un redoublement *hamtu*.
