# Leçon 8 – Verbes transitifs : Maru

## Résumé

**Verbes transitifs**

Les verbes transitifs au présent/futur (Maru) sond formés avec des suffixes similaires à ceux des verbes intransitif

| Personne | Préfixe  | Exemple            |
| -------- | -------- | ------------------ |
| SG 1     | /-en/    | *i3-la2-en*        |
| SG 2     | /-en/    | *i3-la2-en*        |
| SG 3     | /-e/     | *i3-la2-e*         |
| PL 1     | /-enden/ | *i3-la2-en-de3-en* |
| PL 2     | /-enzen/ | *i3-la2-en-ze2-en* |
| PL 3     | /-e-ne/  | *i3-la2-e-ne *     |
