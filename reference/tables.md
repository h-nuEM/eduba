# Tables grammaticales

## Les cas nominaux

| Suffixe | Cas | Fonction |
|---|---|---|
| ∅ (zéro) | Absolutif | Sujet intransitif, objet direct |
| **-e** | Ergatif | Sujet transitif (agent) |
| **-ak** | Génitif | Possession |
| **-ra** | Datif | Bénéficiaire |
| **-a** | Locatif | Lieu statique |
| **-ta** | Ablatif | Origine, provenance |
| **-še<sub>3</sub>** | Terminatif | Direction, but |
| **-da** | Comitatif | Accompagnement |
| **-gin<sub>7</sub>** | Équatif | Comparaison |

## Préfixes casuels verbaux

| Préfixe | Cas correspondant |
|---|---|
| -ma- / -ra- / -na- | Datif (1sg / 2sg / 3sg) |
| -da- | Comitatif |
| -ni- | Locatif |
| -ta- | Ablatif |
| -ši- | Terminatif |

## Copule

| Forme | Sens |
|---|---|
| **-me-en** | je suis / tu es |
| **-me-en-den** | nous sommes |
| **-am<sub>3</sub>** | il / elle est |
| **-me-eš** | ils / elles sont |

## Aspects verbaux

| Aspect | Nom | Sens |
|---|---|---|
| Accompli | **ḫamtu** | action achevée, ponctuelle |
| Inaccompli | **marû** | action en cours, habituelle, répétée |
